# Изображения для сайта ТверьНефтеРегион

Размещайте реальные фотографии в соответствующих подпапках.

## Структура

| Папка | Назначение | Рекомендуемый формат |
|-------|-----------|---------------------|
| `hero/` | Главное изображение на первом экране | 1600×1200, WebP/AVIF |
| `products/` | Фото/образцы нефтепродуктов | 800×500 |
| `transport/` | Сертифицированный транспорт | 1200×800 |
| `delivery/` | Процесс поставки | 1200×800 |
| `documents/` | Документы (без чувствительных данных) | 800×600 |
| `team/` | Команда, ответственные лица | 800×600 |
| `cases/` | Кейсы поставок | 800×500 |
| `og/` | Open Graph изображение | 1200×630 |

## Правила

- Не использовать стоковые фото чужих бензовозов и нефтяных вышек
- Не включать чувствительные данные документов (ИНН, печати, подписи)
- Использовать реальные фото компании после согласования
- Оптимизировать перед загрузкой (WebP/AVIF, сжатие)

## Подключение

После добавления файлов обновите поле `image` в `src/content/products.ts` или через CMS.

Пример: `image: '/images/products/diesel.webp'`
